# Jev Workbench icon

The playful experiment buddy was generated with the Higgsfield connector using
GPT Image 2.5 on September 19, 2026. The geometric emblem references the TypeSafe
logo from https://docs.typesafe.ai/; the goggles, face, and spark give this
independent Workbench app its own identity. This is not an official TypeSafe icon.

`jev-workbench.png` is the original generated artwork and the Qt window icon.
`jev-workbench.ico` contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel sizes
for Windows title bars, Explorer, and shortcuts. Windows embeds it through
`desktop/app.rc`; both assets are built into the application.
