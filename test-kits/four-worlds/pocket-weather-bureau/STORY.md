# The Pocket Weather Bureau

![A brass travel case turned into a magical miniature weather bureau](../assets/pocket-weather-bureau.png)

Nim is a tiny apprentice forecaster who carries an entire weather bureau in a
travel case: a rain gauge, a sun dial, a pressure tube, and a small cloud that
insists on wearing goggles. Nim's dream is modest and heroic: no traveler
should be surprised by a storm because someone assumed a glowing icon meant
more than it did.

The Barometer Bandit is a mischievous gust that lives in the case's hinge. It
does not control the weather. It just swaps readings, removes timestamps, and
puts a cheerful sun dial beside an alarming rain gauge to see who is paying
attention.

## Story arc

1. **The travel case opens.** Five island reports appear as bright picture
   cards. Each has a human-scale choice: pack, watch, or ask for another
   reading.
2. **The Bandit's swap.** The Kite Festival has two readings for the same
   hour. The player learns that conflicting evidence should not become a
   confident recommendation.
3. **The gentle forecast.** A partial clue can still deserve attention. Nim
   chooses watch rather than pretending every uncertainty is an error.
4. **The case clicks shut.** The final lesson is durable: the illustration
   makes the work feel lovely, but the structured observations make it
   trustworthy.

## Why it belongs in a terminal demo

This is the bridge between code and atmosphere. The terminal can display the
world title, icons, short facts, and a precise per-card result. The original
cover art can appear beside a quickstart page or a local file preview, but the
exercise never relies on image recognition. A developer can run it anywhere
with Python and still get an experience that feels designed.
